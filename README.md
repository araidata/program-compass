# Program Compass

Internal cybersecurity strategic planning application. The application includes recorded capability assessments, current and target maturity, operational KPIs, analytics, CSV exports, organizational configuration, accounts and change history. The working continuation adds personnel/positions and reporting lines, capability person ownership, immutable capability/KPI snapshots, and Business Context objectives/threats/dependency analysis. Framework Alignment, Roadmap, Technology and Reports remain placeholders; full workforce capacity and multiyear planning are incomplete. Authentication is temporarily disabled at the owner's request; all visitors can access and edit the site until restoration is requested.

Use Node 24 and npm ci. Follow [DEPLOYMENT.md](docs/DEPLOYMENT.md) for the existing Vercel/Neon configuration, environment variables, controlled migrations, seed and first administrator provisioning. Run npm run dev after configuring ignored .env.local. Local and CI builds succeed without credentials. Vercel deployments apply reviewed migrations and idempotent seeds as documented in DEPLOYMENT.md. The application uses the configured PostgreSQL database at runtime.
