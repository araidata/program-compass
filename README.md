# Program Compass

Internal cybersecurity strategic planning application connecting business context, capability and framework assessments, planning deficiencies/responsibilities, workforce and technology requirements, initiatives, funding scenarios, five-year planning and leadership reports. The implementation preserves the original 30 capabilities and 60 KPIs and includes versioned provisional methods, immutable historical cycles, sourced workload/capacity calculations, Decimal finances and validated relational data exchange. See PROJECT_STATUS and CONTINUATION for actual test/release state; a local implementation is not a verified production release. Authentication remains disabled until Aaron explicitly requests restoration. Desktop only, supported from 1280 px.

Use Node 24 and npm ci. Follow [DEPLOYMENT.md](docs/DEPLOYMENT.md) for the existing Vercel/Neon configuration, environment variables, controlled migrations, seed and first administrator provisioning. Run npm run dev after configuring ignored .env.local. Local and CI builds succeed without credentials. Vercel deployments apply reviewed migrations and idempotent seeds as documented in DEPLOYMENT.md. The application uses the configured PostgreSQL database at runtime.

Read [PROJECT_STATUS.md](docs/PROJECT_STATUS.md), [ARCHITECTURE.md](docs/ARCHITECTURE.md), [PROJECT_SCOPE.md](docs/PROJECT_SCOPE.md), [FUNCTIONAL_REQUIREMENTS.md](docs/FUNCTIONAL_REQUIREMENTS.md), [IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md) and [DECISION_LOG.md](docs/DECISION_LOG.md) before development. Remaining strategic-planning implementation is now authorized by the owner; completion is tracked against all eight owner-approved milestones. Read [CONTINUATION.md](docs/CONTINUATION.md) for the Claude handoff, actual validation and exact remaining work. Desktop-only support is permanent at 1280 px and above; do not develop or test a mobile site.

Validation and browser/database test procedures are in [TESTING.md](docs/TESTING.md). Backend conventions and role matrix are in ARCHITECTURE; implemented entities and future relationships are in [DATA_MODEL.md](docs/DATA_MODEL.md).
