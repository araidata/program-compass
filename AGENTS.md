## Desktop-only support — permanent owner instruction (2026-11-24)

Program Compass is a desktop-only application, supported at viewport widths of 1280 px and above. Do not spend development or QA effort on mobile/phone layouts, mobile navigation, responsive mobile behavior, or mobile screenshots. Do not run or add mobile browser projects. Existing mobile accommodations may remain, but must not drive design or acceptance. Preserve desktop keyboard accessibility, WCAG AA contrast, labelled controls and readable tables. This supersedes earlier mobile/responsive requirements, including P-08 phone reading support. Reintroduce mobile support only if Aaron explicitly requests it.
