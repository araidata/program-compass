# Implementation plan

1. **Phase 0 — Foundation:** application shell, placeholders, development tooling, deployment readiness, shared instructions. Stop here until further authorization.
2. **Phase 1 — Secure persistence:** provision Neon through Vercel, approve domain schema and migrations, implement native authentication and server-side authorization before organizational data is introduced.
3. **Phase 2 — Assessment:** business context, current state, and compliance across the three cybersecurity pillars.
4. **Phase 3 — Resources and portfolio:** people, capacity, and technology planning.
5. **Phase 4 — Strategy and findings:** strategic plans, risk tracking, and prioritization.
6. **Phase 5 — Reporting and hardening:** reporting, accessibility, operational monitoring, and release validation.

Each phase requires separately approved scope and meaningful validation. Follow [ARCHITECTURE.md](ARCHITECTURE.md).
